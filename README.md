# Викторина в стиле «Своей игры»

Онлайн-викторина для компании: один человек — ведущий, остальные — игроки. Три раунда, табло с темами и номиналами, скрытые карточки-модификации и вопросы из Excel-таблицы. Сайт запускается на вашем ноутбуке, игроки заходят по коду комнаты.

> **Статус:** готова серверная часть (комнаты, правила, раунды, модификации, чтение Excel). Интерфейс (страницы входа, игрока и ведущего) добавляется следующим шагом. Пока в `public/` лежит страница-заглушка «Сервер работает».

## Возможности

- Комнаты по 4-буквенному коду; роль ведущего получает создатель комнаты, остальные — игроки.
- Уникальный ник у каждого, включая ведущего.
- 3 раунда по 5 тем × 5 вопросов, сложность растёт сверху вниз.
- Вопросы берутся из `questions.xlsx` и перечитываются при создании комнаты, поэтому перезапускать сервер после правки таблицы не нужно.
- Кто первым нажал «Ответить», тот и отвечает; верность ответа определяет ведущий, правильный ответ виден только ему.
- Модификации, скрытые среди обычных клеток.
- Возврат в игру после потери связи: со своим счётом и состоянием.
- Итоговая таблица и объявление победителя (при равенстве очков победителей несколько).

## Требования

- Node.js (версия LTS, скачать на nodejs.org).
- Интернет нужен только для установки зависимостей и для доступа игроков извне.

## Установка и запуск

```bash
npm install        # один раз: установить зависимости
npm run sample     # создать пример questions.xlsx (перезапишет существующий!)
npm start          # запустить сервер
```

После запуска в терминале появятся адреса:

- `http://localhost:3000` — на этом компьютере;
- `http://192.168.x.x:3000` — для устройств в той же Wi-Fi сети.

Остановить сервер: `Ctrl+C`. Порт можно сменить переменной окружения `PORT`.

### Игра через интернет

Чтобы игроки подключались не из вашей Wi-Fi сети, откройте доступ к порту 3000 через туннель, например:

```bash
ngrok http 3000
```

Отправьте игрокам выданную ссылку `https://…`. Ноутбук должен быть включён, не уходить в сон и оставаться онлайн на время игры. Сервер отдаёт наружу только папку `public/`, файл с вопросами и ответами недоступен по ссылке.

## Формат questions.xlsx

Используется первый лист книги.

| Тема   | Вопрос 1 | Ответ 1 | Вопрос 2 | Ответ 2 | … |
|--------|----------|---------|----------|---------|---|
| Кино   | …        | …       | …        | …       |   |
| Кино   | …        | …       | …        | …       |   |
| Кино   | …        | …       | …        | …       |   |
| Кино   | …        | …       | …        | …       |   |
| Кино   | …        | …       | …        | …       |   |
| Музыка | …        | …       |          |         |   |

- Колонка A — название темы. Одна тема занимает **5 строк подряд**: номер строки внутри темы определяет сложность (1-я строка — самый лёгкий вопрос, 5-я — самый сложный).
- Правее идут пары колонок «вопрос — ответ». Это запасные варианты вопроса для данной клетки: при создании игры из каждой строки случайно выбирается один непустой вариант. Достаточно одной пары, но несколько вариантов делают каждую игру разной.
- Первая строка со словом «Тема» считается шапкой и пропускается. Пустые строки игнорируются.
- Нужно минимум **15 полных тем** (5 строк, в каждой хотя бы один вопрос): по 5 тем на каждый из 3 раундов, темы между раундами не повторяются. Если тем меньше, сервер сообщит об ошибке при создании комнаты.

## Правила игры

**Раунды и номиналы** (сверху вниз по сложности):

| Раунд | Номиналы                       |
|-------|--------------------------------|
| 1     | 100 / 200 / 300 / 400 / 500    |
| 2     | 200 / 400 / 600 / 800 / 1000   |
| 3     | 300 / 500 / 800 / 1000 / 1500  |

**Ход игры**

1. Ведущий создаёт комнату, игроки входят по коду, затем ведущий нажимает «Начать игру».
2. Первого выбирающего сервер назначает случайно. Выбирающий называет тему и сумму, ведущий открывает эту клетку на своей панели.
3. Игроки видят вопрос, ведущий видит ещё и правильный ответ. Первый нажавший «Ответить» отвечает устно, ведущий нажимает «Верно» или «Неверно».
   - **Верно:** игрок получает очки вопроса и выбирает следующую клетку.
   - **Неверно:** с игрока снимаются очки вопроса, повторно на этот вопрос он отвечать не может, остальные снова могут нажать кнопку.
4. Игрок может воздержаться: очки не снимаются, он выбывает из этого вопроса. Ведущий может в любой момент завершить вопрос, тогда никому очки не снимаются.
5. Если никто не ответил верно (все ошиблись, воздержались или ведущий завершил вопрос), следующего выбирающего сервер назначает случайно.
6. Лимита времени на ответ нет. Счёт может уходить в минус.
7. Раунд заканчивается, когда использованы все 25 клеток; затем сразу начинается следующий. После 3-го раунда показываются победитель и итоговая таблица.

**Модификации.** В каждом раунде 4 случайные клетки (настраивается) скрыто заменены карточками. На табло они выглядят как обычные клетки с суммой. При выборе такой клетки вопроса нет: на экранах появляется надпись «МОДИФИКАЦИЯ», эффект получает тот, кто выбирал клетку, а клетка исчезает.

| Карточка        | Эффект                                                                                      |
|-----------------|---------------------------------------------------------------------------------------------|
| Минус           | знак очков игрока меняется на противоположный (насовсем)                                    |
| Бонус           | +500 / 1000 / 1500 / 2000 очков                                                             |
| Штраф           | −500 / 1000 / 1500 / 2000 очков                                                             |
| Обмен очками    | игрок называет, с кем поменяться; ведущий выбирает этого игрока в списке, очки меняются местами |
| Передача хода   | право выбрать следующую клетку переходит следующему игроку по порядку входа в комнату          |

После модификации (кроме «Передачи хода») право выбора остаётся у того же игрока.

## Настройки

В начале `server.js`:

| Константа           | Что задаёт                                          | По умолчанию                   |
|---------------------|-----------------------------------------------------|--------------------------------|
| `PORT`              | порт сервера                                        | 3000                           |
| `MODS_PER_ROUND`    | число клеток-модификаций в каждом раунде            | 4                              |
| `MOD_AMOUNTS`       | возможные суммы бонуса и штрафа                     | 500, 1000, 1500, 2000          |
| `VALUES`            | номиналы клеток по раундам                          | см. таблицу правил             |
| `MODIFIER_SHOW_MS`  | сколько секунд показывается надпись «МОДИФИКАЦИЯ»   | 4000 мс                        |

## Возврат в игру после обрыва связи

Браузер запоминает секретный токен участника. После обновления страницы или потери интернета нужно открыть сайт заново, участник вернётся в ту же комнату со своим счётом. Если токен потерян (другой браузер или устройство), можно войти в комнату под тем же ником, пока прежнее подключение неактивно.

## Ограничения

- Состояние комнат хранится в памяти сервера. После перезапуска `npm start` все комнаты и игры исчезают.
- Присоединиться к уже начавшейся игре с новым ником нельзя, только вернуться под прежним.
- Если ведущий отключился, игра ждёт его возвращения.

## Для разработчиков: события Socket.IO

Клиент → сервер:

- вход: `create_room {nick}`, `join_room {code, nick}`, `rejoin {code, token}` (все с callback `{ok, …}`);
- ведущий: `start_game`, `open_cell {id}`, `judge {correct}`, `end_question`, `pick_swap_target {id}`, `skip_modifier`, `adjust_score {id, delta}`, `new_game`;
- игрок: `buzz`, `abstain`.

Сервер → клиент: одно событие `state` с полным снимком игры, подготовленным под роль получателя (правильный ответ получает только ведущий, тип клетки не раскрывается никому).
